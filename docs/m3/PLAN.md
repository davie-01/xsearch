# XSearch M3 计划：日常资料

依据 ARCHITECTURE §18 M3：XLSX/XLS、PPTX、OFD；完整窗口、收藏；通配符、正则、size/dm、邻近查询及其设置开关；废纸篓。通过条件：你日常用的真实文档都能稳定定位。

| 分块 | 内容 |
|---|---|
| M3-1 提取 | XLSX/XLS（calamine，按行锚点“Sheet1!A12”）、PPTX（按幻灯片锚点，含备注）、OFD（按页锚点，按 Document.xml 页序）；内容类型与设置开关 |
| M3-2 语法 | 名称模式运算符（空格 / 引号 / `\|` / `-`，与内容模式共用）、通配符（`*` `?` `**`）、`regex:`、`size:`、`dm:`、邻近查询 `"甲 乙"~N`；设置中各自的开关，关闭时按普通字符搜索；⌘/ 速查标出开关状态 |
| M3-3 窗口 | 完整窗口（⌘E：范围树、类型/时间/匹配模式过滤、可排序表格、预览、多选拖出）；阅读窗口（⌘↵：PDF 原页面高亮、命中列表、在外部打开到第 N 页）；收藏（⌘D，空输入显示收藏与最近打开）；移到废纸篓（⌘⌫，确认） |
| M3-4 设置与收尾 | 内容匹配模式三选一；打开方式（编辑器打开到行、PDF 外部打开到页）；进度文档 |
