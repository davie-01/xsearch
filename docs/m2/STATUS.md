## 验收证据

- **正确性**：M0 全部语料与表达式在三种模式、目录/扩展名/范围过滤下与暴力扫描对照，3000+ 组 0 差异；变异测试可发现召回缺陷。
- **新建 → 搜到 → 定位**：真实文件 + 真实 FSEvents + 真实提取进程的端到端测试，覆盖新建、修改、移动（含移出范围）、删除、损坏文件。
- **崩溃重放**：在暂存后、批次记录后、索引提交后、确认后 4 个点模拟崩溃，重启后旧版本不残留、新版本可搜。解析卡死被隔离；提取途中文件被改会重新提取。
- **真实样本**：M0 的 12 份文档全部不退化（DOCX 12,347 段 0 丢失）。
- **性能**（2 万份/180 MB 合成语料）：首屏 P95 约 2 ms；高频词全部核验约 0.8 s（渐进返回）。

## 与架构的差异（已写入 ARCHITECTURE）

- ExtractionWorker 是打包的辅助可执行文件而非 XPC Service；IndexService 暂在应用进程内独立队列运行。
- 内容任务由对账器在同一事务中写入，内容水位与名称水位合一。
- 重建内容索引期间的新变化只写入新实例，读取端在切换前看到的是旧实例。
