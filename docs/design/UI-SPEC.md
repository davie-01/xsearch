# XSearch 界面与交互规范

> 版本：v1.3（2026-10-30）
> 对应架构：`docs/ARCHITECTURE.md` v0.7.1
> 原型：`docs/design/prototype/*.dc.html`（Claude Design 画布源文件，在线画布“XSearch 界面原型”可交互查看）
> 设计变量：`docs/design/design-tokens.json`
> 本版只定义**浅色外观**。深色外观在 M1 实现时按第 2.3 节的映射规则补齐。

---

## 1. 设计原则

> v1.3 变更：启动器复现 macOS 26 Spotlight 的形态与动画。呼出时只有一条胶囊搜索框（高 58，圆角为高度一半），打字不改变形态，有结果时向下展开成圆角 26 的整体。移动鼠标后，搜索框向左收窄，“名称”“内容”两个 58pt 圆形玻璃按钮从搜索框右端像液体一样分离出来（`NSGlassEffectContainerView`，融合距离 12，搜索框与按钮间距 20、按钮间距 14）。动画参数按 Spotlight 录屏逐帧测得：搜索框立即收窄（弹簧周期 0.36 秒、阻尼 0.5，明显回弹）；约 20 ms 后各按钮依次（间隔 18 ms）从搜索框当前右端以 30% 大小冒出，边放大边弹到位（位置：周期 0.34、阻尼 0.38，到位时左右晃动约 27% / 8%；大小：周期 0.3、阻尼 0.62），分离时可见液体颈部；图标和选中色在圆分开后（约 0.16 秒起）淡入。收回时按钮先缩回搜索框右端，搜索框随后展开。结果区收起：内容约 40 ms 淡出，停顿 0.1 秒，高度快速收回（周期 0.2、阻尼 0.95）；展开时高度立即增长、内容随后淡入。动画逐帧直接设置视图几何（显示刷新驱动），因为 Core Animation 的帧动画不会带动玻璃形状；每次呼出恢复为单条搜索框。选中模式的按钮为浅强调色玻璃、图标为强调色。系统“减少动态效果”打开时不做动画。空输入不显示最近打开，只显示搜索框。
>
> v1.2 变更：启动器改为接近 macOS 26 Spotlight 的样式（第 4.1、4.2、4.6 节）：Liquid Glass 半透明材质、圆角 26；输入框 26 号，下方一条两端内缩的细分隔线；“名称 / 内容”改为输入框右侧的两个图标按钮；结果用系统文件图标，选中为半透明浅色圆角底（不再是强调色实心底），文字颜色不变；过滤条件为半透明胶囊；输入 `in ` 后前缀变成“内容”标签并从输入框移除。原型文件未同步修改，以本节为准。
>
> v1.1 变更：去掉拼音搜索，名称模式只按文件名中的字面字符匹配（见 ARCHITECTURE.md D13）。原型中的拼音示例和拼音开关已同步删除。

1. **键盘优先**：所有操作都能用键盘完成，鼠标只是补充。
2. **原生观感**：用 macOS 系统字体、系统控件和 Liquid Glass 材质，不自定义花哨样式。
3. **结果先于装饰**：命中位置、文件状态比视觉效果更重要。
4. **不沉默失败**：搜不到、搜不全、索引过期，都要说明原因，不能只显示“没有结果”。
5. **中文优先**：界面文案为简体中文，排版遵循中文习惯（中英文之间留空格，见第 9 节）。

### 2.2 实现映射（AppKit）

- 能用系统语义色的地方优先用系统色：`labelColor`、`secondaryLabelColor`、`tertiaryLabelColor`、`separatorColor`、`controlAccentColor`。上表的十六进制值是原型里的参考值，也是自绘部分的取值。
- **强调色**：默认跟随系统强调色（`controlAccentColor`），原型中的 `#0A5CC2` 只是示意。用户把系统强调色设为黄色、橙色时，命中高亮要保持可区分，改用描边加粗的方式。
- **命中高亮色**不跟随系统，固定使用 `hit` / `hit.current`。

### 2.3 深色外观（待实现时补齐）

- 文字和分隔线全部改用系统语义色，自动适配深色。
- 命中高亮在深色下改为：`hit` → `rgba(255,214,10,0.35)`，`hit.current` → `#FF9F0A`，文字改为 `#000000`，保证对比度。
- 提示条、标签底色使用对应颜色的 20% 透明度版本，文字使用浅色版本。
- 深色外观的原型在 M1 补画后再确认。

- 启动器面板使用 macOS 26 的 `NSGlassEffectView`（原型中用 `rgba(250,250,252,0.90)` 加 30px 背景模糊示意），边框 1px `rgba(255,255,255,0.7)`。

## 4. 组件规范

### 4.1 启动器头部

自左到右：放大镜图标（24）→ 模式标签（内容模式时出现）→ 输入框（26 号，占满剩余宽度）→ 模式切换（两个图标按钮）。头部下方是一条 1pt、两端各内缩 20 的分隔线（`labelColor` 14% 透明度）。

- **模式切换**（v1.2）：输入框右侧两个 32×32 图标按钮，名称 `doc.on.doc`、内容 `text.magnifyingglass`；选中项为圆形浅色底（`labelColor` 12%），未选中为三级文字色。提示文字“按文件名搜索（⌘1）”“在文件内容中搜索（⌘2）”，无障碍角色为单选组。
- **“内容”标签**：输入 `in ` 时出现，`accent.soft` 底、`accent.softText` 字，右侧带 × 按钮，点击后移除前缀并回到名称模式。
- **过滤标签**：`dir:`、`ext:` 识别后显示在输入框下方一行，灰底小标签。
- **占位符**：名称模式“搜索应用、文件和文件夹（输入 in 加空格搜索内容）”；内容模式“在文件内容中查找”。

### 4.2 名称模式结果行

- 分组：有查询时为“应用”“文件与文件夹”；空输入时为“收藏”“最近打开”。分组标题 11.5 号半粗、`text.tertiary`。
- 每行（高 52）：系统文件图标（34×34，应用显示自身图标）→ 文件名（15 号，命中部分强调色半粗）+ 路径（第二行，12 号）→ 右侧元信息（“应用”、修改时间或“文件夹”；`.framework` 等包按文件显示日期）。
- 选中行（v1.2）：半透明浅色圆角底（`labelColor` 11%，圆角 10），文字颜色不变。

### 4.3 内容模式结果项

- 第一行：类型色块（小号）+ 文件名（半粗）+ 右侧“N 处”。
- 第二行：命中片段（前后约 14 / 32 个字，超出部分用省略号），命中处用 `hit` 高亮。
- 第三行：路径 · 修改时间，右侧可选状态标签。
- 选中态同 4.2。

### 4.4 预览面板

- **头部**：文件名、路径 · 位置说明（如“PDF 第 14–15 页”“工作表 Sheet1”）→ “第 n/N 处” → 上一处 / 下一处按钮（30×28）→ 主按钮“定位到原文件 ⌘↵”。
- **正文**：每段左侧显示锚点（`p.14`、`段 13`、`表 2·B3`、`B12`），11 号 `text.placeholder`，右对齐，宽 54；正文 14.5 号，行高 1.8。
- **高亮**：所有命中 `hit`；当前命中 `hit.current` 加光圈，并自动滚动到可见区域。
- **滚动条命中标记**：右侧 6px 宽的竖条，每处命中画一个 3px 高的标记，当前命中用 `hit.current`。

### 4.5 状态标签

| 标签 | 样式 | 触发条件 |
|---|---|---|
| N 页等待 OCR | warn | PDF 中有页没有文字层 |
| 部分索引（原因） | warn | 超出大小或解析上限 |
| 索引待更新 | info | 文件修改后还没重新提取 |
| 磁盘离线 · 卷名 | neutral | 外置盘已拔出（M4） |
| 仅云端 · 只索引文件名 | neutral | iCloud 等文件不在本地 |

### 4.6 提示条

- 黄色提示条（`warn`）：短查询说明、文件已变化、外部打开受限、MCP 隐私提示。
- 灰色提示块：“没有结果”的原因列表，每条附一个可执行的链接（如“把 ~/Desktop 加入内容范围”）。

### 4.7 按钮与控件

- 主按钮：`accent` 底白字，圆角 7–8。
- 次按钮：白底，1px `border.control` 边框。
- 破坏性按钮：文字用 `danger`。
- 开关：40×24，开 `switch.on`、关 `switch.off`，白色圆钮 20×20。实现时直接用 `NSSwitch`。
- 最小点击区域 28×28（桌面应用），开关和主要按钮不小于 24 高。

### 4.8 底栏

左侧是当前模式可用的快捷键提示（粗体键名 + 说明），右侧是状态：
- 名称模式：“名称索引 N 项 · N 个结果 · 耗时”；
- 内容模式：“内容索引 N 个文件 · 待处理 N · N 个文件已核验”。

### 5.2.1 Tab：按应用或位置缩小范围（仅文件名搜索）

参照 Spotlight（macOS 26）。苹果帮助：“输入应用名称（如 Mail、备忘录、预览），然后按 Tab 键，Spotlight 会在指定的应用中搜索”；位置（如 iCloud Drive）同理。TidBITS：“只显示该应用能打开的文档”。

- 在**名称模式**下，选中**应用**按 Tab：输入框前出现带图标的应用标签（显示本地化名称），只列出该应用在 Info.plist（`CFBundleDocumentTypes`）里声明能打开的文档。判断方式：按扩展名查到对应的 UTI，看它是否属于声明的类型（例如 `public.image` 包含 PNG、HEIC），同时兼容只列扩展名的旧式声明。角色为 None 的类型、`public.item` / `public.data` 这类泛类型，以及文件夹、包、应用包等容器类型都不算文档。输入框为空时列出该应用能打开的全部文档。
- 选中**文件夹**按 Tab：出现文件夹标签，只在其中搜索（等同于 `dir:`）。
- 没有选中应用或文件夹时，Tab 照旧把焦点移到结果列表。
- 输入框为空时按 ⌫：先删范围标签，再删“内容”标签。
- **内容模式不使用这条规则**：切到内容模式（`in `、⌘2）时会清掉范围标签，内容搜索不带任何范围条件，Tab 照旧切换焦点。
- 与 Spotlight 的区别：邮件、备忘录等应用自己的私有数据（由应用交给 Spotlight 索引）不在 XSearch 的索引里，所以对这类应用只能找到它们能打开的文件；没有声明任何文档类型的应用会提示无法缩小范围。

### 5.3 输入法

输入法还在组合（有 marked text）时：
- 不按拼音字母触发搜索，结果保持上屏之前的状态；
- 空格、回车、方向键、数字键全部交给输入法，不打开文件、不移动选择。

## 6. 各界面的交互规则

### 6.1 启动器

- 呼出时输入框获得焦点，并选中上次的输入（可以直接覆盖）。
- 默认以名称模式呼出；设置中可以改为“记住上次的模式”。
- 模式切换时保留输入内容和过滤条件。
- 输入后立即搜索，名称模式不加延迟；内容模式在输入停顿约 80ms 后开始，新的输入会取消旧查询。
- 内容模式选中某个结果后，右侧立即预览，并滚动到第一处命中。
- 结果列表先显示片段；总命中数等选中文件之后再计算。

### 6.2 完整窗口

- 与启动器共用同一个查询，展开后保留输入、模式、选中项。
- 左侧：内容索引范围树（可勾选）、文件类型、修改时间、匹配模式。
- 中间：结果表格，列为名称、位置、命中、大小、修改时间，点击表头排序，再点一次反向。支持多选和拖出。
- 固定窗口，点击外部不关闭。

### 6.3 阅读窗口

- PDF 显示原始页面，命中处直接画在页面上；左侧列出全部命中，点击即跳页定位。
- 工具栏提供“在外部打开到第 N 页”：Skim 直接跳页；“预览”需要辅助功能权限，没有授权时提示并打开到第 1 页。
- 打开前核对文件版本，如果文件已变化，就不画高亮，显示提示并重新排队。

### 6.4 设置

标签顺序：通用、索引范围、搜索语法、打开方式、诊断、隐私与数据。
- **索引范围**：文件名、内容两张卡片。
  - 文件名：整盘 / 指定文件夹、排除规则；
  - 内容：文件夹列表（文件数、占用、状态、移除）、添加文件夹、待回收空间、提取的文件类型、单文件上限。
- **搜索语法**：运算符、通配符、正则、邻近查询各一个开关，每项带示例；内容匹配模式三选一（宽松 / 区分大小写 / 严格原文）。
- **诊断**：输入或拖入路径，逐项列出：文件名范围、内容范围、访问权限、提取状态、最近一次索引，每项给出原因和处理办法。
- **隐私与数据**：说明数据位置和权限；“重建内容索引”“清除全部索引”；MCP 开关（默认关闭，开启时显示隐私提示）。

### 6.5 首次启动引导

1. 快捷键（⌥Space）+ 开机自动启动；
2. 内容索引范围：只推荐“下载”，可以取消，也可以添加其他文件夹；
3. 完全磁盘访问：可选，不授权也能正常使用；
4. 完成页：“按 ⌥Space 试一下”。

### 6.6 菜单栏

图标为放大镜线条图标。菜单内容：
- 文件名索引状态；
- 内容索引进度条和当前处理位置；
- 打开搜索；
- 暂停 / 恢复建立内容索引；
- 设置；
- 诊断；
- “用电池时自动暂停大批量处理”的说明；
- 退出。

## 7. 状态与反馈

| 场景 | 表现 |
|---|---|
| 名称没有结果 | 显示“文件名索引中没有匹配‘…’的项目”，并链接到可能的原因 |
| 内容没有结果 | 列出原因：范围之外的同名文件（附“加入内容范围”）、提取失败（附详情）、等待处理的文件数 |
| 重查询（单字、正则） | 先显示已核验的结果，底部显示进度条和“仍在搜索… 已核验 x / y”，可以停止 |
| 2 字节查询 | 提示条说明召回方式，结果完整 |
| 1 字节查询 | 提示条建议加上 dir: 或 ext:，会扫描全部已存储的正文 |
| AND 组合含短词 | 说明“先用长词找候选，再核验短词” |
| 文件已变化 | 预览中不画高亮，显示黄色提示条，自动重新排队 |
| 输入法组合中 | 结果不变，按键交给输入法 |
| 索引进行中 | 菜单栏显示进度；已处理的文件可以立即搜索 |

## 8. 无障碍

- 所有可操作元素都用真实控件（按钮、输入框、复选框、开关），可以用 Tab 到达。
- 只有图标的按钮必须有无障碍标签（如“上一处”“移除内容前缀”）。
- 文字对比度不低于 4.5:1（包括 11 号的灰色说明文字）。
- 不只用颜色表达状态：状态标签都带文字；当前命中除了颜色，还有光圈。
- 支持系统“减少动态效果”：关闭面板宽度过渡等动画。

## 9. 文案规则

- 简体中文，句子简短，直接说结果和原因。
- 中文与英文、数字之间留一个空格（“第 3 页”“100 MB”“PDF 第 14 页”）。
- 快捷键写法：⌥Space、⌘↵、⇧⌘G（符号在前，无空格）。
- 路径用 `~/` 开头的写法。
- 状态说明要给出下一步怎么做，例如“把 ~/Desktop 加入内容范围”，而不是只说“不在范围内”。
- 不出现“错误”“失败”之外的技术术语（如 trigram、op_seq）；需要时在诊断详情中展示。
