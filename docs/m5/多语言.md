# 界面语言（简体中文 / English）

设置 › 通用 › 语言：跟随系统（默认）/ 简体中文 / English。切换后重新启动 XSearch 生效（设置里有“立即重启”按钮）。

## 做法

- **中文是源语言。** 界面文字照常用中文写在代码里，统一包一层 `L("中文")`；带参数的写成 `L("共 %@ 项", "\(n)")`。英文在 `Packages/XSearchCore/Sources/Strings+en.swift`，以中文原文为键。
- **英文复数：** 英文写成 `"%@ file‖%@ files"`，第一个数字参数为 1 时用前半段。
- **同词不同义：** 同一个中文在英文里说法不同时用 `L("收藏", context: "group")`，表里写 `"收藏#group"`。
- **引擎和索引来的消息**（诊断、提取警告、页眉页脚等部件名、正则报错）仍以中文存储和传递，界面显示时用 `Loc.display(_:)` 翻译；带数字或名称的用 `englishPatterns` 里的正则匹配。
- **语言设置就是本应用的 `AppleLanguages`。** 这样系统绘制的界面（打开面板、Sparkle 更新、权限提示）也跟着切换。权限提示的英文在 `App/Resources/en.lproj/InfoPlist.strings`。只有同时带 en 和 zh-Hans 两个本地化的 app 包才会显示英文；测试、XPC 服务等其他进程一律中文。
- **搜索语法**的中文写法（`kind:文档`、`今天`、`7天` 等）在英文界面下照样可用。
- 开发时可用 `XS_LANG=en` 临时以英文启动。

## 新增界面文字时

1. 用 `L("…")` 包住中文；确实不该翻译的（例如语言自己的名字“简体中文”）在该行末尾写 `// l10n: 原因`。
2. 在 `Strings+en.swift` 里加英文。
3. `LocalizationTests` 会检查：每个 `L("…")` 都有英文，界面代码里没有漏包的中文字符串。
