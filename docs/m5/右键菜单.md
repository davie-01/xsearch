# 启动器结果的右键菜单

适用于启动器的名称列表和内容列表（完整窗口暂不含）。代码在 `App/Sources/ResultMenu.swift`，接入在 `LauncherPanel.swift` 的 `contextMenu(content:row:)`。

## 依据

- 公开资料里查不到 macOS 26 Spotlight 结果右键菜单的完整条目，只能确认 Spotlight 对选中结果支持 `⌘I` 显示简介、`⌘C` 拷贝文件。
- 因此以访达的文件右键菜单为基准（打开、打开方式、快速查看、拷贝、移到废纸篓等），按结果类型裁剪，并沿用启动器已有的快捷键。

## 交互

- 右键一行时，这一行先成为选中项，菜单里的操作都作用于它；表格不再另画方框。
- 分组标题行没有菜单。
- 菜单项右侧显示的快捷键只是提示，对应启动器里已有的按键。
- 打开类操作会收起启动器；复制、收藏等操作保留启动器，并在底栏短暂提示结果。

## 各类结果的菜单

| 结果类型 | 菜单项 |
|---|---|
| 普通文件（名称） | 打开 ↵ · 打开方式 ▸ · 在访达中显示 ⌘↵ · 快速查看 空格 · 复制“文件名” · 复制路径 · 收藏 / 取消收藏 ⌘D · （最近打开中：从最近打开中移除） · 移到废纸篓 ⌘⌫ |
| 文件夹 | 打开 · 在访达中显示 · 快速查看 · 在终端中打开 · 复制 · 复制路径 · 收藏 · 移到废纸篓 |
| 应用 | 打开 · 在访达中显示 · 复制 · 复制路径 · 收藏（不提供快速查看和移到废纸篓：在搜索列表里误删应用的代价太大） |
| 内容命中 | 打开 ↵ · 在阅读窗口中打开 ⌘↵ · 打开方式 ▸ · 在访达中显示 · 快速查看 · 复制 · 复制路径 · 收藏 · 移到废纸篓 |
| 压缩包内的文件 | 打开（先解出再打开） · 在阅读窗口中打开 · 在访达中显示压缩包 · 复制路径（“包路径!/成员路径”）；不能单独复制、收藏或删除 |
| 已不存在的文件（收藏、最近打开里） | 从收藏中移除 · 从最近打开中移除 · 复制路径 |

说明：
- **打开方式**：列出能打开该文件的应用，默认应用排第一并标“（默认）”，同名应用只列一次。
- **复制“文件名”**：把文件本身放到剪贴板，可以在访达里粘贴出一份副本。
- **复制路径**：纯文本的完整路径。原来的 `⇧⌘C` 快捷键已移除。
- **移到废纸篓**：和 `⌘⌫` 相同，先在底部提示条里确认。
- 内容模式下 `⌘↵` 是阅读窗口，所以“在访达中显示”在内容命中里不标快捷键；内容列表里空格不触发快速查看（右侧已有预览），菜单项也不标空格。

## 没有做的

- **显示简介**：需要通过 AppleScript 控制访达，会触发“自动化”权限弹窗，暂不提供。
- **完整窗口的结果表格**：还没有右键菜单。

## 开发用检查

- `XS_TYPE` 里的 `☰`：把当前选中行的菜单逐项写入 `XS_TYPE_LOG`，同时记录该行在屏幕上的位置（用于真实右键测试）。
- `XS_MENU_DO=标题前缀`：配合 `☰` 执行对应菜单项后记录状态。
