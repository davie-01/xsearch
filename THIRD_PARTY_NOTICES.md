# Third-party inputs

- Unicode `CaseFolding-17.0.0.txt` is from https://www.unicode.org/Public/17.0.0/ucd/CaseFolding.txt. It is redistributed under Unicode License V3; the complete notice is in `Tests/Fixtures/m0/licenses/UNICODE-LICENSE.txt`. Rust's build script generates a full, default (C/F, non-Turkic) case-fold table from this pinned input.
- `unicode-normalization` 0.1.25 supplies Unicode 17.0.0 decomposition tables. Its upstream licenses remain applicable. The M0 test checks the Unicode version explicitly.
- UniFFI 0.29.5 (MPL-2.0, https://github.com/mozilla/uniffi-rs) generates the Swift bindings in `Packages/ContentEngine/Sources/Generated.swift` and `Packages/ContentEngine/xs_ffiFFI/include/xs_ffiFFI.h` (via `scripts/gen-bindings.sh`); its runtime support code is linked into `libxs_ffi.a`. MPL-2.0 is file-level copyleft: modifications to UniFFI's own files must stay under MPL-2.0; the generated files and this project's code are not affected.
- calamine 0.30.1 (MIT, https://github.com/tafia/calamine) reads XLSX / XLS / ODS spreadsheets for content extraction (M3); it is statically linked into `libxs_ffi.a`.
- regex 1.13 / regex-syntax 0.8 (MIT OR Apache-2.0, https://github.com/rust-lang/regex) evaluate `regex:` in content search; statically linked into `libxs_ffi.a`.
- Rust dependencies and exact versions are recorded in `Cargo.lock`; their upstream licenses remain applicable. This is a local validation workspace, not a release distribution or a completed license inventory.
- The synthetic text, DOCX and PDF fixtures are generated by this project's scripts. Real sample documents remain user-owned and are never copied into the source fixtures or public report.
- No implementation code was copied from the research repositories mentioned in the architecture document during M0.
